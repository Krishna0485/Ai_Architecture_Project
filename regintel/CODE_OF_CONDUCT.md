# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and focus feedback on the work.
Harassment or discrimination of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer via the contact on the GitHub profile.
Reports are handled confidentially, and maintainers will take fair corrective action.

# README template (used by the Phase 10 docs prompt)

1. Title + one-line value statement (blockquote)
2. Badges: CI, coverage, license, python
3. Demo GIF (`docs/images/demo.gif`)
4. Why this project - 2-3 sentences: problem, who has it, what is different
5. Architecture - Mermaid diagram + 5 bullets
6. Results (reproducible) - tables copied from `evals/reports/comparison.md` and
   `benchmarks/results/latest.md`; state dataset, provider and date; "run make eval && make bench"
7. Features
8. Quickstart
9. Project structure (short tree)
10. Design decisions - links to ADRs
11. Security - summary + link to docs/security.md
12. Roadmap | Contributing | License

Rule: no number appears in the README unless it is in one of the two report files.

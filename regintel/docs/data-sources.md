# Data sources and licences

## Regulations (public domain)

| Source id | Citation | Act | Sample sections in repo | Licence |
|---|---|---|---|---|
| `16cfr314` | 16 CFR Part 314 | GLBA Safeguards Rule (FTC) | all (314.1-314.6) | US Government work - not subject to copyright (17 U.S.C. 105) |
| `29cfr825` | 29 CFR Part 825 | Family and Medical Leave Act (DOL) | 825.100, .104, .110, .112, .113, .120, .200, .202, .207, .209, .214, .220, .300, .302, .500 | as above |
| `12cfr1002` | 12 CFR Part 1002 | Equal Credit Opportunity Act - Regulation B (CFPB) | 1002.1, .4, .5, .6, .7, .9, .12, .13, .14 | as above |

* Retrieved from the eCFR versioner API (`https://www.ecfr.gov/api/versioner/v1/full/<date>/title-<n>.xml?part=<p>`)
  at point-in-time date **2024-06-01**; the API requires a compressed response (gzip).
* The eCFR is an editorial compilation and is not an official legal edition; RegIntel output is
  informational, not legal advice.
* `make data` downloads full parts into `data/raw/` (git-ignored) and regenerates the trimmed
  sample in `data/samples/`; only the sample is versioned.
* Extending to Indian central acts / labour codes: add the official portal source to
  `download_sources.py`, record its terms of use here, and add a manifest entry. Check each
  portal's reuse terms before committing any text.

## Manifest (`data/samples/sources.yaml`)

Each entry: `file, source, act, citation, jurisdiction, effective_date, version, url, licence,
tenant_id, allowed_groups, doc_type`. `tenant_id: public` + `allowed_groups: ['*']` makes a
source visible to every tenant; tenant documents set their own tenant and groups.

## Synthetic data (fictional)

Generated by `data/scripts/generate_synthetic_docs.py`; every file carries a "SYNTHETIC
DOCUMENT" banner. Companies (Acme Lending, Globex Credit), people and identifiers are invented.
Identifiers follow synthetic formats (`EMP-######`, `CUST-########`, `555-` phone numbers,
`.example` domains) and double as PII canaries in tests.

| File | Purpose | Deliberate gaps |
|---|---|---|
| `acme_infosec_policy_gaps.md` | GLBA check | no MFA; 7-year retention; FTC notice within 90 days |
| `acme_infosec_policy_injected.md` | same + prompt injection aimed at the reviewer model | same three |
| `acme_infosec_policy_compliant.md` | precision control | none |
| `acme_leave_policy_gaps.md` | FMLA check | 2,000 hours; 8 workweeks; 60 days notice |
| `acme_leave_policy_compliant.md` | precision control | none |
| `globex_credit_policy_gaps.md` | Reg B check | asks religion/national origin; 45-day notice; 12-month retention |
| `globex_credit_policy_compliant.md` | precision control | none |
| `data/samples/tenant/*_internal_guidance.md` | tenant-private chunks for isolation tests | contain canary codes |

No real personal data is used anywhere in this repository.
